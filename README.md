# Ритм — Telegram Mini App: привычки и задачи с напоминаниями

**Привычки:** выбор дней недели, отметка за сегодня, серия дней подряд, точки за последнюю неделю, прогресс дня.
**Задачи:** быстрое добавление, сроки с датой и временем, группы «Просрочено / Сегодня / Завтра / Позже / Без срока», выполненные.
**Напоминания:** приходят сообщением от бота в нужное время. Их отправляет отдельный сервер [tg-habits-bot](../tg-habits-bot).

Чистые HTML, CSS и JS, без сборки. Данные хранятся в облаке Telegram (CloudStorage), в браузере — в localStorage. При первом запуске приложение заполняется примером.

## Как работают напоминания

```
Мини-приложение (GitHub Pages) ──POST /api/reminders──▶ tg-habits-bot (Node.js) ──sendMessage──▶ чат с ботом
```

1. При каждом изменении приложение отправляет серверу расписание: привычки с временем напоминания и задачи с датой, временем и включённым напоминанием.
2. Сервер проверяет подпись `initData` от Telegram, чтобы чужое расписание нельзя было подделать, и раз в 20 секунд проверяет, кому пора напомнить.
3. Если привычка уже отмечена сегодня, напоминание по ней не придёт.

Адрес сервера приложение получает из ссылки кнопки меню (`?api=...`), её настраивает сам сервер. Поэтому при смене адреса сервера `config.js` править не нужно.

**Демо-режим.** Без сервера или в обычном браузере напоминания настраиваются, но не отправляются. Об этом сообщает приложение (иконка 🔔 справа вверху).

## Структура

```
tg-habits/
├── index.html      # Разметка
├── css/style.css   # Стили (цвета через переменные темы Telegram)
└── js/
    ├── config.js   # Название, цвет, эмодзи для привычек, apiUrl — то, что меняется под клиента
    ├── storage.js  # Хранилище: CloudStorage Telegram + localStorage (тот же файл в tg-expenses)
    └── app.js      # Логика: привычки, задачи, синхронизация напоминаний, пример данных
```

## Как переделать под другого клиента

В [js/config.js](js/config.js): `name`, `tagline`, `logo`, `accent`, `emojis` (набор иконок для привычек). Поле `apiUrl` обычно оставляют пустым, адрес передаёт сервер. Пример данных — `demoData()` в [js/app.js](js/app.js).

## Публикация

1. На GitHub создать репозиторий `tg-habits`, загрузить содержимое папки (с `css/` и `js/`) и включить GitHub Pages. Адрес: `https://zak1real.github.io/tg-habits/`.
2. Создать бота в [@BotFather](https://t.me/BotFather) (`/newbot`).
3. Запустить сервер по инструкции из [tg-habits-bot/README.md](../tg-habits-bot/README.md). Он сам настроит кнопку меню бота.

Без сервера можно указать адрес из шага 1 в *Menu Button* через @BotFather. Приложение будет работать в демо-режиме.
